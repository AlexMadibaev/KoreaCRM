# Просмотр кассы без EXE и базы данных

Дважды нажмите `Открыть демо кассы.cmd` в корне проекта. Он запустит локальные серверы и откроет кассу в браузере. Пока серверы работают, изменения интерфейса появляются после обновления страницы.

Демо-сервер работает только на этом компьютере. Запустите его из корня проекта:

```powershell
node apps/pos/demo-server.mjs
```

Откройте `http://127.0.0.1:5173/` в браузере и введите:

- Адрес сервера: `http://127.0.0.1:3001`
- Логин: `demo`
- Пароль: `demo1234`

Если запускаете вручную, выполните `corepack pnpm --filter @koreacrm/pos dev --host 127.0.0.1` в отдельном терминале. Демо-сервер должен продолжать работать.

После входа нажмите «Подключить кассу». Для поиска товара введите `крем`, `сыворотка` или `пенка`. Штрихкод крема: `4600000000011`.

Данные демонстрационные и хранятся только в памяти процесса. При перезапуске сервера продажи и кассовые смены сбрасываются. Для реальной работы нужен API с PostgreSQL и учётная запись, созданная через seed или администрирование.

Офлайн-вход после перезапуска доступен в настольном EXE после успешного онлайн-входа, подключения кассы и сохранения каталога. Используйте тот же адрес сервера, логин и пароль. Локальный вход действует семь дней; продажи в этот период сохраняются на устройстве и отправляются после восстановления связи. Браузерная демоверсия для просмотра интерфейса требует работающий сервер.

Если до отключения была открыта кассовая смена, наличные продажи можно сохранять офлайн. Касса показывает их в ожидаемой сумме смены и обновляет сумму по серверу после отправки. Пока наличная продажа ожидает отправки, закрытие смены недоступно.

Если сервер отклонит сохранённую продажу, откройте её карточку в Центре синхронизации. Там видны причина и детали чека. После устранения причины нажмите «Повторить после исправления»; касса отправит ту же операцию повторно.

После продажи откройте «История чеков» в нижней части кассы. Чек можно найти по номеру `DEMO-0001` или телефону выбранного при продаже клиента, посмотреть товары и оплату и снова вывести нефискальный чек для печати. История загружается с сервера.
