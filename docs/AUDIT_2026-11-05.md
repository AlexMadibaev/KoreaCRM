# Аудит KoreaCRM против мастер-ТЗ «CloudShop-level POS/CRM» (05.11.2026)

Состояние по коммиту `a0170ad` (main = origin/main на момент аудита). Стек: pnpm + Turbo монорепо; API — NestJS 11, Prisma 6, PostgreSQL 16; кабинет — Next.js 15/React 19; касса — Vite/React 19 + Tauri 2 (Rust, локальная SQLite); общие токены — `packages/ui/src/tokens.css` (бренд `#F2979C`, текст `#424242`). 29 миграций, 186 автотестов (все проходят).

Функции CloudShop взяты с публичных страниц cloudshop.ru/allfeatures и /features.php; ранее сопоставление экранов делалось по 14 снимкам пользователя (`docs/CABINET_CLOUDSHOP_REDESIGN.md`).

## Ограничения среды проверки

Тесты этого этапа выполнены в облачной Linux-среде: PostgreSQL 16, собранный API и сценарии через HTTP. Windows EXE здесь собрать и прогнать нельзя (нужны Windows, Rust MSVC и WebView2), поэтому «200 чеков через интерфейс EXE» этим этапом **не выполнены**. Прямой загрузки нативных движков Prisma в среде нет: для тестового стенда клиент Prisma генерировался в режиме `engineType = "client"` с официальным драйвером `@prisma/adapter-pg`. Рабочий код и схема при этом не менялись.
