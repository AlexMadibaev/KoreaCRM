# Дизайн-система Korea CRM

Версия 1.0. Основа — согласованный интерфейс Windows-кассы и цвета логотипа `full_logo_ks_dark.svg`. Эта система предназначена для кассы, личного кабинета и следующих экранов продукта. Общие токены подключены к кассе и веб-кабинету.

## Где находится источник истины

- Цвета, отступы, скругления и тени: [`packages/ui/src/tokens.css`](../packages/ui/src/tokens.css).
- Повторно используемые классы компонентов: [`packages/ui/src/components.css`](../packages/ui/src/components.css).
- React-кнопка с вариантами: [`packages/ui/src/button.tsx`](../packages/ui/src/button.tsx).
- Композиция и плотность экрана кассы: [`apps/pos/src/pos-redesign.css`](../apps/pos/src/pos-redesign.css).
- Композиция веб-кабинета: [`apps/web/app/design-system.css`](../apps/web/app/design-system.css).
- [Визуальный образец](DESIGN_SYSTEM_PREVIEW.html) можно открыть в браузере как обычный локальный HTML-файл.

Токены подключаются **до** CSS конкретного приложения. Не копируйте шестнадцатеричные цвета в новый экран: используйте `var(--ks-...)`. Локальные значения допустимы только для уникальных иллюстраций или статусов, которых ещё нет в системе; повторяющееся значение сначала добавьте в токены.

## Характер

Спокойный рабочий интерфейс: белые поверхности внутри светлого корпуса, мягкий розовый для действий и выделения, тёмно-серый для текста. Касса должна оставаться читаемой при плотном каталоге и длинном чеке. Декоративный цвет не должен конкурировать с суммой оплаты и текущим действием.

### Цвет

| Токен | Значение | Применение |
| --- | --- | --- |
| `--ks-color-brand` | `#F2979C` | Основное действие, акцент, внешний фон кассы. Это точный цвет логотипа. |
| `--ks-color-brand-hover` | `#E98289` | Наведение на основное действие. |
| `--ks-color-brand-strong` | `#A44F59` | Акцентный текст и ссылки на белом фоне. |
| `--ks-color-brand-soft` | `#FFEFF0` | Выбранный пункт меню, мягкий акцент. |
| `--ks-color-brand-wash` | `#FFF3F4` | Наведение на карточку, лёгкая подложка. |
| `--ks-color-brand-subtle` | `#FFF7F8` | Большие спокойные розовые поверхности. |
| `--ks-color-ink` | `#424242` | Основной текст и текст на розовой кнопке. Это точный цвет логотипа. |
| `--ks-color-text-muted` | `#726B6B` | Вторичный текст. |
| `--ks-color-surface` | `#FFFFFF` | Карточки и формы. |
| `--ks-color-canvas` | `#F4F4F6` | Фон внутри приложения. |
| `--ks-color-border` | `#EDEDF0` | Обычные разделители. |
| `--ks-color-border-brand` | `#EDCDD0` | Граница выделенного или акцентного блока. |
| `--ks-color-success` | `#21865F` | Успешная связь и завершённые операции. |
| `--ks-color-warning` | `#74520E` | Предупреждения, требующие внимания. |
| `--ks-color-danger` | `#A4413A` | Ошибки и опасные действия. |

Текст `#424242` на основной розовой заливке имеет контраст около **4,63:1**. Поэтому основная кнопка использует тёмный текст; белый текст на этом розовом фоне не применять. Акцентный текст `#A44F59` на белом имеет контраст около **5,47:1**. Для текста меньше 18 px целевой контраст — не ниже 4,5:1.

### Типографика и размеры

- Семейство: `Segoe UI`, затем `Inter`, `Arial`, `sans-serif`; системный шрифт обеспечивает одинаковый вид в Tauri на Windows.
- Заголовок экрана: 24 px, 700. Заголовок панели: 18–20 px, 700. Основной текст и поля: 13–14 px. Подписи и метаданные: 12 px. Меньший текст используйте только для декоративных меток и при достаточном контрасте.
- Денежные значения выделяются весом 700–800; для итоговой суммы размер 17–24 px. Числа выравниваются по правому краю внутри итоговых блоков.
- Высота обычной кнопки или поля — минимум 40 px. Компактная кнопка 32 px допустима в плотных строках, если рядом есть понятная подпись.

### Ритм и геометрия

Шкала отступов: `4 / 8 / 12 / 16 / 24 / 32 px` (`--ks-space-1` … `--ks-space-6`). Между полями в форме обычно 12–16 px; между крупными секциями 24–32 px. Скругления: 8 px для контролов, 12 px для малых карточек, 17 px для панелей, 23 px для внешнего корпуса. Сильная тень допустима только у внешнего корпуса; внутренние панели разделяются тонкой границей.

## Компоненты и состояния

| Компонент | Правило |
| --- | --- |
| Кнопка `primary` | Одно главное действие на смысловой блок. Розовая заливка, тёмный текст. Disabled сохраняет надпись и теряет насыщенность. |
| Кнопка `secondary` | Вспомогательное действие: светлая розовая подложка и акцентный текст. |
| Кнопка `ghost` | Ненавязчивое действие без рамки. Для опасного действия используйте отдельное подтверждение в конкретном сценарии. |
| Кнопка `danger` | Красный цвет только для действительно опасной операции. |
| Поле `ks-field` | Видимая подпись над полем, пример допустимого ввода при необходимости, фокус с розовым кольцом. Ошибка объясняет, как исправить значение. |
| Карточка `ks-card` | Белая поверхность и тонкая граница. Вся кликабельная карточка должна иметь доступное имя и состояние фокуса. |
| Статус `ks-badge` | Короткая надпись вместе с цветом; состояние нельзя передавать только цветом. |
| Пункт меню | Выбранный пункт имеет `aria-current="page"`, мягкую розовую подложку и акцентный текст. Каждый пункт открывает самостоятельный экран. |

В кассе самостоятельные экраны: **Касса**, **История чеков**, **Кассовая смена**, **Синхронизация**. Текущая корзина сохраняется при переключении; действия продажи остаются на экране кассы. Сообщение об ошибке показывайте рядом с действием и через `role="alert"`, уведомление об успехе — через `role="status"`.

## Использование

```tsx
import { Button } from '@koreacrm/ui';

<Button variant="primary" type="submit">Сохранить</Button>
<Button variant="secondary" size="sm" onClick={refresh}>Обновить</Button>
```

```css
@import '../../../packages/ui/src/tokens.css';
@import '../../../packages/ui/src/components.css';

.my-panel {
  padding: var(--ks-space-5);
  border: 1px solid var(--ks-color-border);
  border-radius: var(--ks-radius-lg);
  background: var(--ks-color-surface);
  color: var(--ks-color-ink);
}
```

В новом экране сначала используйте существующие токены и компоненты, затем уточняйте локальную композицию. Проверяйте обычное, hover, focus, disabled, пустое, загрузочное и ошибочное состояния. На ширине 720 px элементы перестраиваются в одну колонку; данные и действия остаются доступны без горизонтальной прокрутки. Логотип берите из брендового SVG, не заменяйте его самодельной буквой.

## Проверка изменений

После правки общих токенов проверьте кассу и веб-кабинет: `typecheck`, `lint`, `test`, `build`. Затем откройте кассу на экранах входа, продажи, истории, смены и синхронизации, а кабинет — на экранах входа, обзора, каталога и профиля. Проверьте клавиатуру, контраст, мобильную ширину и текст ошибок.
