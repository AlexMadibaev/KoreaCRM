# Локальный запуск MVP

На этом компьютере MVP запускается с отдельной базой `koreacrm_mvp`. Тестовая база остаётся отдельно.

Эта инструкция относится к исходному Windows ПК. Для чистого клона из GitHub используйте [техническую карту](TECHNICAL_SETUP.md): локальный кластер `tools/pg-test-data` не входит в репозиторий.

1. Откройте PowerShell в `D:\KoreaCRM`.
2. Выполните `powershell -ExecutionPolicy Bypass -File .\tools\start-mvp.ps1`.
3. Дождитесь сообщения `MVP ready` и откройте `http://127.0.0.1:3010/login`.

При первом запуске скрипт создаёт базу, применяет миграции, создаёт владельца, собирает API и веб-приложение и печатает начальные логин и пароль. Следующие запуски сохраняют ту же базу и пароль. Для быстрого повторного запуска без сборки добавьте `-SkipBuild`. Если локальный PostgreSQL на порту 5433 остановлен, скрипт запускает существующий кластер `tools/pg-test-data`.

Настройки и журналы находятся в `.mvp-local/`. Файл `mvp.env` содержит пароль и ключ входа; не отправляйте его другим и не удаляйте, если хотите сохранить возможность повторного запуска с тем же паролем. Данные PostgreSQL находятся в установленном локальном сервере PostgreSQL, а не в папке проекта.

Чтобы сохранить копию базы и изображений товаров, выполните `powershell -ExecutionPolicy Bypass -File .\tools\backup-mvp.ps1`. Архивы создаются в `.mvp-local/backups/`. Копируйте их также на другой диск: резервные копии рядом с базой не защищают от поломки компьютера.

На другом устройстве в той же Wi-Fi сети откройте адрес `Wi-Fi/LAN address`, который печатает скрипт. Компьютер с приложением должен быть включён; его IP адрес может измениться после переподключения к сети. Для доступа из интернета понадобится отдельное защищённое развёртывание. Перед вводом реальных данных смените начальный пароль владельца.

Если другой телефон или ПК не открывает страницу, один раз откройте PowerShell **от имени администратора** и выполните `powershell -ExecutionPolicy Bypass -File D:\KoreaCRM\tools\enable-mvp-lan.ps1`. Правило Windows Firewall разрешает порт 3010 только устройствам той же подсети. Если после этого адрес недоступен, проверьте, что устройства подключены к одной Wi-Fi сети без изоляции клиентов.
