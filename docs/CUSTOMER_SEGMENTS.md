# Настройка сегментов клиентов

В личном кабинете откройте **Клиенты → Настроить сегменты клиентов**. Пользователь с правом `settings.edit` может включать и отключать шесть сегментов и менять их пороги: число покупок, сумму, средний чек и периоды в днях. Доступ к просмотру клиентов требует `customers.view`.

Правила сохраняются в PostgreSQL в таблице `CustomerSegmentSettings`. Для существующей базы примените миграцию `20261025150000_customer_segment_settings` через `prisma migrate deploy`. Пока настройки не сохранены, используются прежние пороги: 1 покупка для «Новый», 3 для «Постоянный», 5 покупок и 5 млн сомони для VIP, 90 дней для «Давно не покупал», 500 тыс. сомони для высокого среднего чека, 3 покупки за 30 дней для частых покупок.

API: `GET /customers/segment-settings` и `PATCH /customers/segment-settings`. Сохранение записывается в аудит. Правила применяются сразу к карточке клиента и фильтру списка без пересчёта или изменения самих продаж. Продажи учитываются по всем магазинам; отменённые чеки не входят в расчёт периодов. Сегменты не назначают скидку автоматически: процент скидки хранится отдельно в карточке клиента.
