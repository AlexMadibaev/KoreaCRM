# Перенос каталога Korea от 28.10.2026

При обновлении VPS `compose.production.yaml` запускает `db:seed` с `KOREACRM_IMPORT_LEGACY=1`. Seed один раз переносит данные из `packages/database/prisma/legacy-data/korea-2026-10-28.json`. Завершение фиксируется записью `LEGACY_DATA_IMPORTED` в `AuditLog`; повторные перезапуски не восстанавливают удалённые карточки и не меняют уже созданные записи.

Источник — предоставленные файлы `catalog-1793163121.xlsx` и `КЛИЕНТЫ КОРЕА.xlsx`. Подготовлено 1646 товаров, 2195 уникальных штрихкодов и 1526 клиентов с однозначными телефонами. Ещё 488 строк клиентов исключены из автоматического переноса из-за отсутствующего или неоднозначного телефона, повтора либо некорректного Email. Они сохранены локально в `KoreaCRM-clients-review.xlsx` для ручной проверки.

Существующие товары и клиенты сопоставляются по артикулу и телефону. Их имена, фотографии, история, персональные скидки и прочие данные не перезаписываются. Для новых товаров создаются штрихкоды. Цена из исходника сохраняется в сомони как `priceMinor` для активных магазинов, если настройка товара в магазине ещё отсутствует. В исходнике 17 товаров без положительной цены: она останется пустой до проверки.

Положительные начальные остатки переносятся только в отсутствующие записи по магазинам Sadbarg и Айни и сопровождаются движением `LEGACY_IMPORT`. Соответствующий магазин ищется по имени; при отсутствии создаётся. Магазин «Доставка» не создаётся, поскольку в источнике все его остатки нулевые. **1111 отрицательных значений остатков пропущены**: их нельзя считать доступным товаром. Нулевые остатки также не создают движений. Уже существующие остатки не меняются, чтобы не затереть продажи после даты выгрузки.

Файл данных в репозитории содержит имена и телефоны клиентов. Репозиторий публичный; доступ к этим данным через GitHub не ограничен. При смене способа хранения недостаточно удалить файл из следующего коммита: он останется в истории Git и потребует отдельного удаления из истории.

Для проверки использована отдельная локальная БД `koreacrm_import_verify_20261031`: миграции применены, первый seed создал 1646 товаров, 2195 штрихкодов, 1526 клиентов, 4938 настроек и 679 начальных остатков; второй seed ничего не добавил. Для проверки фактического обновления VPS смотрите журнал контейнера API и запись `LEGACY_DATA_IMPORTED` в журнале действий.
